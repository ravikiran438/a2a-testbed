## How verdicts map back to this doc

Both surfaces (CLI sweep `a2a-testbed conformance <url>` and the
in-browser playground at https://a2a-testbed.com) report results
keyed by contract id (e.g. `transport.streaming_first_event_is_task`).
Look up any contract id under `src/a2a_testbed/contracts/` to find
its module + spec citation; cross-reference the spec section against
the table above to see which category it belongs to.

When comparing verdicts across independent harnesses (see
[discussions/2](https://github.com/ravikiran438/a2a-testbed/discussions/2)
for the cross-harness diff scoping), the spec pin commit on this
page is the version each contract was authored against. A
disagreement on a contract whose section number changed between
spec revisions is a pin-mismatch artefact, not a real divergence.
